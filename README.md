# sDeadItems

sDeadItems — простой плагин для случайной выдачи предметов при смерти игрока.

   Команды:

- /sdi gui — открыть GUI редактор предметов
- /sdi on — включить плагин
- /sdi off — выключить плагин

Алиасы: /sdeaditems

   Возможности:

- Удобный GUI для добавления/удаления предметов прямо в игре
- Случайная выдача одного предмета из списка при смерти игрока
- Включение/отключение без перезагрузки сервера
- Настройка через config.yml
- Лёгкий и оптимизированный
